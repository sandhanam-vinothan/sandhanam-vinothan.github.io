# Vinothan Portfolio V6 — responsive & polished

## What changed
- Full VINOTHAN heading dynamically fits the available width, including landscape screens.
- Official Puzzle Academy logo converted to transparent PNG and centered in the animated 3D-style showcase.
- Fifteen colorful premium PNG icons embedded directly in the website (and provided separately under `assets/icons`).
- Consistent dark/light themes across every section.
- Back-to-top button with smooth scroll and a page progress indicator.
- Responsive refinements for phones, landscape phones, tablets, desktops and ultrawide screens.
- All essential media, CSS, JS and PNG icons are embedded in `index.html`, so GitHub Pages needs **only that one file**.

## Publish through GitHub website
Open https://github.com/sandhanam-vinothan/sandhanam-vinothan.github.io , replace the root `index.html` with this one, and commit the change. Wait for GitHub Pages to finish deploying and reload your website. You do **not** need to upload the `assets` folder because the site is self-contained.

## Local preview
Open `index.html` directly, or run `python -m http.server 5500` in the extracted folder and visit http://localhost:5500 .

The supplied Academy JPEG included a checkerboard-style background. The version embedded in the website is a transparent PNG derived from that supplied image; the visual emblem has been retained.
